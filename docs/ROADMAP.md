# 开发状态与路线图

[← 项目首页](../README.md) · [试用指南](getting-started.md) · [贡献指南](../CONTRIBUTING.md)

路线图按优先级描述方向，不承诺日期。已实现的源码、发布包验收、性能评测与研究实验分别记录。

## 目前已有

- C++23 / CMake 工程、TSF 输入服务、Broker 与版本化本机 IPC。
- librime、固定雾凇数据、字流覆盖层与 Stub 开发路径。
- 组合、候选选择和上屏，中英文 / 简繁 / 标点设置。
- 原生候选栏、WinUI 3 设置、主题预览与部分 SSF 导入。
- Windows 11 x64 的 `0.1.0-alpha.1` 未签名测试预发布；有限功能验收见[发布记录](ALPHA-RELEASE.md)。

以上不等于稳定正式版或所有应用验收通过。

## 优先级 1：可靠输入与安装

- 完善焦点切换、组合生命周期、隐私输入范围与宿主兼容性回归。
- 补齐多显示器 / DPI、候选定位、键盘导航及无障碍验证。
- 验证升级、卸载、重启后的版本一致性及部分安装失败恢复。
- 保持 TSF 宿主内代码轻量、原生，不新增非必要常驻进程。

## 优先级 2：可复核的发布与基线

- 扩展真实 Rime、WinUI 3 与打包检查的自动化覆盖。
- 以合法、可分享的输入集评估候选准确率、纠错风险和学习稳定性。
- 建立真实宿主交互与性能测量方法，记录版本、环境和未覆盖范围。
- 完善依赖许可清单、主题兼容说明与正式版签名方案。

## 研究方向：上下文与小模型

上下文排序、小模型和深融合需要先建立基线、充分评测、隐私边界与失败回退策略。目前没有可发布的模型权重或已证实的产品收益；当前 Alpha 不启用这些能力。

实验能否进入产品取决于候选质量、误纠率、延迟、资源占用和兼容性证据，不能只凭单次训练或少量样例决定。

## 暂不计划

云账号、在线候选、广告、皮肤商城及非必要后台服务。优先把本地输入体验做好。
