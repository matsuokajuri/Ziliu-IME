# 路线图

## 0.1 可编译骨架

- [x] C++23/CMake 工程
- [x] TSF COM 生命周期与按键 sink
- [x] 原生候选窗组件
- [x] 单实例 Broker 消息循环
- [x] 原生设置窗口
- [x] 开发期注册工具
- [x] 平台无关引擎接口与测试
- [x] librime 与雾凇拼音依赖固定
- [x] 不直接修改上游的字流数据覆盖层

## 0.2 能输入“字流”

- Broker 命名管道协议 v1
- librime 适配层
- 雾凇拼音数据 overlay
- TSF composition/edit session
- 候选定位、选择、翻页和上屏
- 记事本、Edge、Office、Windows Terminal 冒烟测试

## 0.3 可自用 Alpha

- 本地用户词库
- 中英文切换、中文标点、模糊音
- 设置持久化与热加载
- 深浅色、多显示器 DPI、候选窗无障碍
- x64/x86 双架构安装与卸载
- 崩溃恢复和本地脱敏日志

## 0.4 词库与纠错基线

- 固定正常输入与错拼测试集
- 精确输入优先的纠错门控
- 用户词频稳定性策略
- 词库更新与许可证清单自动生成
- Top-1、Top-5、误纠率和延迟基准

## 暂不计划

- 云同步、账号和官方服务器
- 在线候选
- AI 改写、翻译或写作
- 广告、推荐、皮肤商城
- 任何非必要常驻进程
