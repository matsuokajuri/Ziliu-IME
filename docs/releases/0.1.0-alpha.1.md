# Ziliu 0.1.0-alpha.1 — unsigned early test release

This is a Windows 11 x64 prerelease for early testing, not a stable version.
Both the ZIP and graphical installer are **unsigned**. Windows SmartScreen may
warn about an unknown publisher or block installation. Download only from this
repository's GitHub Release and compare the published SHA-256 checksums. A hash
checks file integrity; it does not authenticate the publisher. Do not disable
SmartScreen globally. Code signing is deferred until a formal release.

The setup installer needs administrator permission and must run under the
administrator account that will use Ziliu. This alpha does not support entering
credentials for a *different* administrator account from a standard-user session.
Sign out or restart Windows after installing or upgrading, then reopen apps.
Uninstall preserves user settings, custom themes, and Rime user data.

The isolated VM checks cover basic typing in Notepad, Edge, Windows search,
InputScope handling, theme import/use, upgrade, and uninstall. They do **not**
establish compatibility with every application or pixel-level parity for every
custom SSF skin. See [the detailed acceptance record](../ALPHA-RELEASE.md).

The ZIP contains `Install-Ziliu.ps1` and a per-file SHA-256 manifest; use its
`-VerifyOnly` mode to inspect integrity without installing. The graphical setup
embeds that ZIP and verifies its exact SHA-256 before installation. The installer
is not an MSI transaction, and this version does not automatically recover from
every partial-install failure.
